Memory for coding agents

Your agent relearns
your project every
single morning.

It re-reads the same files, works out again the decision you made last Tuesday and asks a question you already answered. Scrollback is not memory: it dies at compaction and again when the session ends. os-brain is the memory that survives both. A new session opens with a short brief, like this one. Then, as you work, your agent is reminded only of what it learned that bears on the task in front of it. Months of memory and the context stays light.

What you will notice

Install it on Friday.
Notice on Monday.

It arrives knowing

No more first-day questions

Your agent opens every session knowing what you decided, what broke last time and how you like to work. You stop answering the same question twice.

Corrections stick

Fix a fact once

Correct it and the old version stops coming back. Ask in last month's wording and you get this month's answer, with a line saying which fact it replaced.

Every repo

Worked out once, found everywhere

Keep your projects in one shared store and what you work out in one repository can be found from any other, whichever agent you have open. A project can also stay out of it.

Lighter context

Fewer tokens, less re-reading

The brief is ranked and cut to 6000 bytes by default (about 1.5k tokens), with the binding rules first. Your agent asks the brain before it searches files, so it stops paying to work out again what an earlier session already found.

Knows how you work

Your habits, kept

Say once how you like to work and what you never want. Every session starts with it, so you stop repeating yourself at the top of every chat.

New projects too

Day one follows your rules

Axioms bind every project on the machine. A repository you created this morning opens its first session already knowing your ways of working.

Your machine, your file

Nothing leaves
the machine.

Each project keeps its memories in brain/brain.db, a SQLite file readable only by you and listed in .gitignore so it never lands in the repository. There is no server to run and no account to make.

os-brain never calls home. There is no telemetry and no update check. The only network code in the binary serves the web UI and the MCP server. Both run only when you start them. What this site and the binary record.

The code is on GitHub under the MIT licence. The storage format is the same one ns-brain uses, so a brain can move to the team edition and back without losing a memory.

The more you use it,
the better it gets.

Free and open source, for one developer on as many projects as you like. You need Go 1.26 or newer.

$ go install github.com/chka/os-brain/cmd/os-brain@latest
$ cd ~/projects/yours && os-brain init
