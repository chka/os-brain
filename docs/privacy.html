Privacy

What gets
recorded and where.

Two separate things: this website and the binary. The website is a set of static pages. The binary makes no network call of its own.

This website

These pages are static files served by GitHub Pages from the docs/ folder of the repository. You can read every one of them there.

We run no analytics and no tracker. There is no page script of ours that reports anything, no advertising and no third-party embed. The only script on a page fades sections in as you scroll and talks to nobody. The typefaces are served from this site too.

No cookies of ours. The site sets no cookie and stores nothing in your browser, so there is nothing to consent to and no banner.

GitHub serves the pages, so GitHub receives the request for each one, as any web host does: your IP address, the page and your browser's user agent. We don't see those logs and have no access to them. GitHub's own privacy statement covers what it keeps.

The binary

os-brain has no telemetry, no update check and no account. It never calls home. Nothing leaves your machine unless you run a command that sends it somewhere.

  • Your memories stay in brain/brain.db in each project and in the shared store at ~/.claude/os-brain/brain.db. Both are SQLite files, readable only by you (mode 600). init adds the project database to .gitignore.
  • Your prompts are stored by the per-prompt hook, word for word up to 8000 characters, for 30 days, in the same local database. Text that looks like a credential is refused. os-brain utterances lists them and os-brain init --no-auto-recall turns the hook off. The install page has the details.
  • Safety copies are written to a backups directory beside the shared store, mode 600, never inside the working tree.
  • The web UI (os-brain ui) listens on 127.0.0.1 by default and only while you run it.
  • The MCP server (os-brain mcp) runs on stdio unless you give it --http. Off loopback it needs a certificate and a token. The MCP page covers the rules.

Two things can run a command you wrote yourself: a probe declared in brain.json to run at session open and a backups.push command that copies a safety copy elsewhere. Each one has to be approved on each machine before it runs, because brain.json is committed and a cloned repository must not run a stranger's command. What they send and where is up to the command you wrote.

Your agent is a separate program. The brief and the memories recall returns go into its context, so they reach whatever model provider that agent uses. That is the agent's traffic, under the agent's own terms.
