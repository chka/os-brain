One binary. Your memories live in a SQLite file on your own machine. Your agent reaches them in three ways: the session hooks bring them in without being asked, while shell commands and MCP are how the agent asks the brain and writes to it. Start with install. Read the memory model once, because it explains every time the brain says no. Keep the CLI reference open.

For the agent, not for you

Two documents ship
inside the binary.

os-brain init writes both into the brain directory, brain/, so your agent already has them without downloading anything. It does not edit your CLAUDE.md. Both are also in the root of the repository.

HOWTO.md is the how: which command to use, what each flag changes and what the output looks like. BEST-PRACTICES.md is the when: what is worth saving, what the code or git already says (so saving it is noise) and how to write a title you can still find months later.

On the command line, os-brain help lists every command and os-brain help <command> prints its flags.
